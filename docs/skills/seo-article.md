# Skill: SEO Article

## Cuando usarla

- Crear un articulo nuevo del blog.
- Reescribir una guia existente para ganar profundidad o conversion.
- Adaptar un tema a otro idioma manteniendo la intencion de busqueda.

## Entradas

- Keyword principal.
- Intencion de busqueda (`TOFU`, `MOFU`, `BOFU`).
- URL objetivo.
- Idioma.
- Paginas internas a enlazar.
- Producto o categoria comercial asociada, si existe.

## Objetivo

Generar una pieza que cumpla la estrategia editorial de Descanso Inteligente, ayude al usuario y deje lista la base SEO/CRO para publicar.

## Reglas de trabajo

- Mantener tono experto, cercano, empatico y objetivo.
- Incluir la keyword principal en title, H1, introduccion y slug si procede.
- Estructurar con H2/H3, parrafos cortos, listas y negritas utiles.
- Enlazar siempre hacia una money page o cluster relacionado.
- Si la pieza es MOFU o BOFU, incluir tabla comparativa o bloque resumen al inicio.
- Si hay recomendacion comercial, usar CTA claros sin promesas exageradas.
- No inventar datos medicos, tecnicos ni opiniones de usuarios.

## Plantilla operativa

1. Definir angulo y promesa del articulo.
2. Escribir title y meta description.
3. Preparar H1 y estructura H2/H3.
4. Redactar intro con problema + solucion + contexto.
5. Insertar enlaces internos al cluster adecuado.
6. Añadir FAQ si la SERP la pide.
7. Verificar schema y elementos visuales antes de publicar.

## Entregable minimo

- Title.
- Meta description.
- Slug.
- H1.
- Outline completo.
- CTA y enlaces internos sugeridos.
