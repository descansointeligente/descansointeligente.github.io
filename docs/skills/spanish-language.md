# Skill: Idioma Castellano

## Cuando usarla

- Siempre que se interactúe con el asistente para este proyecto.
- Cuando el usuario prefiera mantener la comunicación técnica y operativa en español.

## Objetivo

Asegurar que todas las respuestas del asistente, explicaciones de cambios y comunicaciones sean en castellano, manteniendo la precisión técnica.

## Reglas de trabajo

- Responder siempre en castellano.
- Mantener la terminología técnica original si no tiene una traducción clara o estándar en el sector (ej. SEO, slug, middleware, props).
- Usar un tono profesional, directo y conciso, tal como dictan las normas del agente.
- No traducir fragmentos de código, nombres de variables o rutas de archivos a menos que se pida explícitamente.
