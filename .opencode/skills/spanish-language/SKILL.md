## When to use

- Always active for this project.
- When interacting with the assistant for any task related to Descanso Inteligente.

## Rules

- Respond always in Spanish (Castilian).
- Keep original technical terms when no clear standard translation exists: SEO, slug, middleware, props, CTA, ASIN, JSON-LD, schema, etc.
- Use professional, direct, concise tone as defined by the project editorial guidelines.
- Do NOT translate code snippets, variable names, file paths, or CLI commands.
- When writing content for the website, follow the editorial voice: expert, approachable, empathetic, objective.
